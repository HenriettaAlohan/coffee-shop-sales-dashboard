# Coffee Shop Sales Performance Dashboard
![Coffee Shop Sales Dashboard](images/Coffeee_profile_pic.png)
## Overview
This project analyzes sales performance across multiple coffee shop locations using Excel. It transforms raw transactional data into an interactive dashboard that provides insights into revenue trends, customer behavior, product performance, and peak transaction periods.

## Objectives
- Analyze sales performance across multiple locations  
- Identify peak sales hours and high-traffic days  
- Evaluate product category performance  
- Track monthly revenue trends  
- Support data-driven business decisions  

## Tools Used
- Microsoft Excel  
- Pivot Tables  
- Charts & Dashboards  
- Data Cleaning & Transformation  

## Key Insights
- Revenue performance varies significantly by location  
- Peak transactions occur during specific hours of the day  
- Beverage category drives the highest sales volume  
- Certain days of the week show higher customer activity  
- Monthly trends highlight seasonal fluctuations in revenue  

## Dashboard Features
- Revenue by Month  
- Transactions by Day of Week  
- Transactions by Hour of Day  
- Product Category Performance  
- Location-based Sales Comparison  

## Project Outcome
This dashboard helps stakeholders optimize staffing, improve inventory planning, and enhance decision-making through clear data visualization and actionable insights.
